# Drop .ogg files here to activate sounds. See Scripts/audio_manager.gd for filenames.

Copia aquí los archivos con estos nombres (`.ogg`, o `.wav`); suenan solos y, si faltan, el juego sigue en silencio.

| Archivo | Suena | |
|---|---|---|
| `morning_ambience.ogg` | en casa durante la mañana del tutorial | bucle suave: pájaros, un vehículo de vez en cuando, hojas |
| `shower.ogg` | mientras se ve la ducha | bucle |
| `stomach.ogg` | al ponerse el uniforme, cuando ruge el estómago | efecto corto |
| `click.ogg`, `coin.ogg`, `coin_spend.ogg`, `sleep_start.ogg`, `alarm.ogg`, `correct.ogg`, `wrong.ogg` | interfaz | efectos cortos |
